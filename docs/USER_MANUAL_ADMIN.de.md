## Empfehlungen {#recommendations}

### Übersicht {#overview}

Fügen Sie über das mehrstufige Empfehlungsformular neue Orte hinzu, bearbeiten Sie bestehende Einträge oder entfernen Sie Empfehlungen.

### Empfehlung hinzufügen {#how-to-add-a-recommendation}

1. Wenn Sie sich beim Namen des Betriebs nicht sicher sind, suchen Sie ihn in Google Maps.
2. Suchen Sie den Betrieb, den Sie empfehlen möchten.
3. Kopieren Sie den Namen genau so, wie er in Google Maps angezeigt wird. Die Website verwendet Google-Daten, um die übrigen Informationen automatisch auszufüllen.

![Find business name on Google Maps](screenshots/screenshotsreal/how-to-add-a-recommendation-1.jpg)

1. Klicken Sie auf [**Add Recommendation** (Empfehlung hinzufügen)](/members/admin/listings/new).

![Add Recommendation](screenshots/screenshotsreal/how-to-add-a-recommendation-2.jpg)

1. Wählen Sie eine Kategorie aus.
2. Klicken Sie auf **Next** (Weiter).

![Select category](screenshots/screenshotsreal/how-to-add-a-recommendation-3.jpg)

1. Suchen Sie den Betrieb anhand seines Namens in Google Maps.
2. Klicken Sie auf den richtigen Betrieb, um ihn auszuwählen.

![Search and select business](screenshots/screenshotsreal/how-to-add-a-recommendation-4.jpg)

1. Prüfen Sie, ob der angezeigte Standort korrekt ist.
2. Klicken Sie auf **Next** (Weiter), um fortzufahren.

![Confirm location](screenshots/screenshotsreal/how-to-add-a-recommendation-5.jpg)

1. Warten Sie, während die Website die weiteren Informationen aus Google Maps abruft.
2. Klicken Sie auf **Next** (Weiter), um fortzufahren.

![Wait for Google data](screenshots/screenshotsreal/how-to-add-a-recommendation-6.jpg)

1. Fügen Sie weitere Kontaktdaten hinzu.

![Add extra contact](screenshots/screenshotsreal/how-to-add-a-recommendation-7.jpg)

1. Wählen Sie die Art der Kontaktinformation aus (z. B. E-Mail oder WhatsApp).
2. Fügen Sie eine zusätzliche Bezeichnung hinzu (z. B. Inhaber oder Reservierungen).
3. Geben Sie die entsprechenden Kontaktdaten ein.
4. Klicken Sie auf **Next** (Weiter), um fortzufahren.

![Fill contact details](screenshots/screenshotsreal/how-to-add-a-recommendation-8.jpg)

1. Fügen Sie die Öffnungszeiten hinzu oder bearbeiten Sie sie.
2. Fügen Sie eine Notiz hinzu (z. B. „nur nach Vereinbarung“).
3. Klicken Sie auf **Next** (Weiter), um fortzufahren.

![Opening hours and note](screenshots/screenshotsreal/how-to-add-a-recommendation-9.jpg)

1. Ergänzen Sie eine persönliche Beschreibung der Empfehlung.
2. Klicken Sie auf **Next** (Weiter), um fortzufahren.

![Add description](screenshots/screenshotsreal/how-to-add-a-recommendation-10.jpg)

1. Warten Sie, während die Website Stichwortvorschläge von OpenAI abruft.
2. Klicken Sie auf **Next** (Weiter), um fortzufahren.

![Wait for keywords](screenshots/screenshotsreal/how-to-add-a-recommendation-11.jpg)

1. Prüfen Sie die vorgeschlagenen Stichwörter.

![Suggested keywords](screenshots/screenshotsreal/how-to-add-a-recommendation-12.jpg)

1. Geben Sie Text ein, um nach vorhandenen Stichwörtern zu suchen.
2. Klicken Sie auf die Stichwörter, die Sie der Empfehlung hinzufügen möchten.

![Search existing keywords](screenshots/screenshotsreal/how-to-add-a-recommendation-13.jpg)

1. Geben Sie ein neues Stichwort vollständig ein.
2. Klicken Sie auf die neuen Stichwörter, die in einem grünen Feld unter der Suchleiste angezeigt werden.

![Create new keyword](screenshots/screenshotsreal/how-to-add-a-recommendation-14.jpg)

1. Prüfen Sie in der Stichwortliste, welche Stichwörter Sie hinzugefügt haben.
2. Klicken Sie auf **Next** (Weiter), um fortzufahren.

![Review keywords](screenshots/screenshotsreal/how-to-add-a-recommendation-15.jpg)

1. Prüfen Sie noch einmal alle Angaben.
2. Klicken Sie auf einen der vorherigen Schritte, um Angaben zu ändern.
3. Klicken Sie auf **Create recommendation** (Empfehlung erstellen), um den Vorgang abzuschließen.

![Create recommendation](screenshots/screenshotsreal/how-to-add-a-recommendation-16.jpg)

### Empfehlung löschen {#how-to-delete-a-recommendation}

1. Klicken Sie auf [**Recommendations** (Empfehlungen)](/members/admin/listings).

![Open Recommendations](screenshots/screenshotsreal/how-to-delete-a-recommendation-1.jpg)

2. Scrollen Sie nach unten.

![Scroll recommendations](screenshots/screenshotsreal/how-to-delete-a-recommendation-2.jpg)

3. Suchen Sie die gewünschte Empfehlung.

![Search recommendation](screenshots/screenshotsreal/how-to-delete-a-recommendation-3.jpg)

4. Klicken Sie auf das **X**.

![Click X](screenshots/screenshotsreal/how-to-delete-a-recommendation-4.jpg)

5. Klicken Sie auf **Delete** (Löschen), um den Vorgang zu bestätigen.

![Confirm delete](screenshots/screenshotsreal/how-to-delete-a-recommendation-5.jpg)

## Mitglieder {#members}

### Übersicht {#overview}

Laden Sie neue Mitglieder per E-Mail ein, geben Sie Mitgliedern Admin-Rechte oder entfernen Sie Mitglieder.

### Neues Mitglied hinzufügen {#how-to-add-a-new-member}

1. Klicken Sie auf [**Add Member** (Mitglied hinzufügen)](/members/admin/invitations).

![Add Member](screenshots/screenshotsreal/how-to-add-a-new-member-1.jpg)

2. Geben Sie eine E-Mail-Adresse oder mehrere E-Mail-Adressen gleichzeitig ein.
3. Klicken Sie auf **Send Invitations** (Einladungen senden).

![Send invitations](screenshots/screenshotsreal/how-to-add-a-new-member-2.jpg)

### Mitglied zum Admin machen {#how-to-promote-a-member-to-admin}

1. Klicken Sie auf [**Members** (Mitglieder)](/members/admin/users).

![Open Members](screenshots/screenshotsreal/how-to-promote-a-member-to-admin-1.jpg)

2. Suchen Sie nach dem gewünschten Mitglied.

![Search member](screenshots/screenshotsreal/how-to-promote-a-member-to-admin-2.jpg)

3. Klicken Sie auf **Promote** (Befördern).

![Click Promote](screenshots/screenshotsreal/how-to-promote-a-member-to-admin-3.jpg)

4. Klicken Sie erneut auf **Promote** (Befördern), um den Vorgang zu bestätigen.

![Confirm Promote](screenshots/screenshotsreal/how-to-promote-a-member-to-admin-4.jpg)

### Mitglied löschen {#how-to-delete-a-member}

1. Klicken Sie auf [**Members** (Mitglieder)](/members/admin/users).

![Open Members](screenshots/screenshotsreal/how-to-delete-a-member-1.jpg)

2. Suchen Sie nach dem gewünschten Mitglied.

![Search member](screenshots/screenshotsreal/how-to-delete-a-member-2.jpg)

3. Klicken Sie auf das **X**.

![Click X](screenshots/screenshotsreal/how-to-delete-a-member-3.jpg)

4. Klicken Sie auf **Delete** (Löschen), um den Vorgang zu bestätigen.

![Confirm Delete](screenshots/screenshotsreal/how-to-delete-a-member-4.jpg)

5. Das Mitglied wurde nun entfernt.

![Member removed](screenshots/screenshotsreal/how-to-delete-a-member-5.jpg)

## News, Events & Activities {#posts}

### Übersicht {#overview}

Erstellen Sie News, Events & Activities-Beiträge über das Artikelformular.

### Neuen News, Events & Activities-Beitrag hinzufügen {#how-to-add-a-new-blog-post}

1. Klicken Sie auf [**Add article** (Neuen News, Events & Activities-Beitrag hinzufügen)](/members/admin/blog/new).

![Add new News, Events & Activities article](screenshots/screenshotsreal/how-to-add-a-new-blog-post-1.jpg)

1. Fügen Sie einen Titel und eine Beschreibung / Einleitung hinzu.
2. Klicken Sie auf **Next** (Weiter).

![Add title and description](screenshots/screenshotsreal/how-to-add-new-artikle-image-1.jpg)

1. Laden Sie ein neues Titelbild hoch.
2. Oder wählen Sie eines der vorhandenen Titelbilder aus.

![Upload or select cover image](screenshots/screenshotsreal/how-to-add-new-artikle-image-2.jpg)

1. Klicken Sie auf **Next** (Weiter).

![Click Next after cover image](screenshots/screenshotsreal/how-to-add-new-artikle-image-3.jpg)

1. Klicken Sie auf **Add location** (Standort hinzufügen).

![Click Add location](screenshots/screenshotsreal/how-to-add-new-artikle-image-4.jpg)

1. Suchen Sie nach einem Unternehmen oder Standort.

![Search for a business or location](screenshots/screenshotsreal/how-to-add-new-artikle-image-5.jpg)

1. Wählen Sie das Unternehmen oder den Standort aus.

![Select the business or location](screenshots/screenshotsreal/how-to-add-new-artikle-image-6.jpg)

1. Überprüfen Sie den Standort und klicken Sie auf **Next** (Weiter).

![Verify location and click Next](screenshots/screenshotsreal/how-to-add-new-artikle-image-7.jpg)

1. Nutzen Sie die Textsteuerung, um den Text im Body-Bereich des Artikels zu gestalten.

![Style text in the article body](screenshots/screenshotsreal/how-to-add-new-artikle-image-8.jpg)

1. Klicken Sie auf **Add image** (Bild hinzufügen), um ein Bild in den Body des Artikels einzufügen.

![Click Add image](screenshots/screenshotsreal/how-to-add-new-artikle-image-9.jpg)

1. Wählen Sie das Bild aus Ihren Dateien aus, das Sie hinzufügen möchten.

![Select image from files](screenshots/screenshotsreal/how-to-add-new-artikle-image-10.jpg)

1. Klicken Sie auf **Open** (Öffnen), um das Bild hochzuladen.

![Click Open to upload image](screenshots/screenshotsreal/how-to-add-new-artikle-image-11.jpg)

1. Klicken Sie auf **Next** (Weiter), um fortzufahren.

![Click Next to continue](screenshots/screenshotsreal/how-to-add-new-artikle-image-12.jpg)

1. Fügen Sie weiteren Text unter dem Bild hinzu.
2. Klicken Sie auf **Next** (Weiter), wenn Sie mit der Bearbeitung des Artikel-Bodys fertig sind.

![Add further text and click Next](screenshots/screenshotsreal/how-to-add-new-artikle-image-13.jpg)

1. Klicken Sie auf **Publish** (Veröffentlichen), um den Artikel zu veröffentlichen.

![Click Publish](screenshots/screenshotsreal/how-to-add-new-artikle-image-14.jpg)

## Website-Inhalte {#website-content}

### Übersicht {#overview}

Mit Content Admin können Sie Texte, Bilder und Blöcke auf Website-Seiten bearbeiten.

### Bild auf Website-Inhalten ändern {#how-to-change-an-image-on-a-blog-post}

1. Klicken Sie auf [**Content Admin**](/admin#/~/place).

![Content Admin](screenshots/screenshotsreal/how-to-edit-the-websites-text-and-images-1.jpg)

2. Klicken Sie auf das Bild, das Sie ändern möchten.

![Select image on page](screenshots/screenshotsreal/how-to-change-an-image-on-a-blog-post-1.jpg)

3. Klicken Sie im TinaCMS-Editor auf das entsprechende Bild.

![Select image in editor](screenshots/screenshotsreal/how-to-change-an-image-on-a-blog-post-2.jpg)

4. Klicken Sie auf **Upload** (Hochladen).

![Click Upload](screenshots/screenshotsreal/how-to-change-an-image-on-a-blog-post-3.jpg)

5. Wählen Sie das Bild aus, das Sie hochladen möchten. (Dieser Schritt kann je nach Gerät etwas anders aussehen.)

![Select file to upload](screenshots/screenshotsreal/how-to-change-an-image-on-a-blog-post-4.jpg)

6. Klicken Sie auf **Open** (Öffnen).

![Click Open](screenshots/screenshotsreal/how-to-change-an-image-on-a-blog-post-5.jpg)

7. Klicken Sie auf **Insert** (Einfügen).

![Click Insert](screenshots/screenshotsreal/how-to-change-an-image-on-a-blog-post-6.jpg)

8. Fügen Sie eine Bildunterschrift hinzu.
9. Speichern Sie Ihre Änderungen.

![Caption and save](screenshots/screenshotsreal/how-to-change-an-image-on-a-blog-post-7.jpg)

### Text auf Website-Inhalten bearbeiten {#how-to-edit-text-on-a-blog-post}

1. Klicken Sie auf [**Content Admin**](/admin#/~/place).

![Content Admin](screenshots/screenshotsreal/how-to-edit-the-websites-text-and-images-1.jpg)

2. Klicken Sie auf ein Feld mit blau gestricheltem Rahmen.

![Click dashed field](screenshots/screenshotsreal/how-to-edit-text-on-a-blog-post-1.jpg)

3. Das zugehörige Eingabefeld wird daraufhin im Formular auf der linken Seite geöffnet.

![Connected input field](screenshots/screenshotsreal/how-to-edit-text-on-a-blog-post-2.jpg)

4. Bearbeiten Sie den Text im Eingabefeld. Ihre Änderungen werden gleichzeitig in der Website-Vorschau angezeigt.

![Live text update](screenshots/screenshotsreal/how-to-edit-text-on-a-blog-post-3.jpg)

5. Speichern Sie Ihre Änderungen, um sie auf der Website zu veröffentlichen.

### Neuen Block hinzufügen {#how-to-add-a-new-block}

1. Öffnen Sie in Content Admin die Seitenübersicht der Seite, die Sie bearbeiten möchten.

![Open page overview](screenshots/screenshotsreal/how-to-add-a-new-block-1.jpg)

2. Klicken Sie auf das Plus-Symbol, um das Auswahlmenü für Blöcke zu öffnen.

![Open blocks menu](screenshots/screenshotsreal/how-to-add-a-new-block-2.jpg)

3. Wählen Sie den gewünschten Block aus (z. B. Text).

![Select a block](screenshots/screenshotsreal/how-to-add-a-new-block-3.jpg)

4. Scrollen Sie in der Website-Vorschau nach unten, um den neuen Block zu sehen.

![New block on page](screenshots/screenshotsreal/how-to-add-a-new-block-4.jpg)

5. Bearbeiten Sie den Text oder andere Inhalte des Blocks.
6. Speichern Sie Ihre Änderungen.

![Update block and save](screenshots/screenshotsreal/how-to-add-a-new-block-5.jpg)

### Blöcke verschieben {#how-to-move-blocks-around}

1. Klicken Sie auf die drei Punkte und halten Sie die Maustaste gedrückt, um den Block zu verschieben.

![Start dragging block](screenshots/screenshotsreal/how-to-move-blocks-around-1.jpg)

2. Ziehen Sie den Block an die gewünschte Position.

![Drag block](screenshots/screenshotsreal/how-to-move-blocks-around-2.jpg)

3. Lassen Sie die Maustaste los. Der Block wird sowohl in der TinaCMS-Seitenleiste als auch in der Website-Vorschau an der neuen Position angezeigt.
4. Speichern Sie Ihre Änderungen.

![Block moved](screenshots/screenshotsreal/how-to-move-blocks-around-3.jpg)

### Block löschen {#how-to-delete-a-blog-post-block}

1. Öffnen Sie in Content Admin die Seitenübersicht der Seite, die Sie bearbeiten möchten.

![Open page overview](screenshots/screenshotsreal/how-to-delete-a-blog-post-block-1.jpg)

2. Klicken Sie neben dem Block, den Sie löschen möchten, auf das Papierkorb-Symbol.

![Click bin icon](screenshots/screenshotsreal/how-to-delete-a-blog-post-block-2.jpg)

3. Der Block wird sowohl aus dem TinaCMS-Editor als auch aus der Website-Vorschau entfernt.
4. Speichern Sie Ihre Änderungen.

![Block removed](screenshots/screenshotsreal/how-to-delete-a-blog-post-block-3.png)
